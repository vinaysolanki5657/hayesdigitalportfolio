HAYES DIGITAL Portfolio — GitHub Pages

Files:
- index.html: complete responsive portfolio website.

Publish on GitHub Pages:
1. Open your GitHub account and create a new public repository named `hayes-digital-portfolio`.
2. Upload `index.html` to the root of the repository.
3. Open repository Settings → Pages.
4. Under Build and deployment, choose “Deploy from a branch”.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait a minute or two. GitHub will show your public site URL.

Your portfolio will typically be:
https://vinaysolanki5657.github.io/hayes-digital-portfolio/

If you use a different repository name, the URL will use that name instead.
